# Affect Bot

Telegram-бот для автоматической модерации русскоязычных чатов. Проект объединяет NLP-модель для поиска токсичных текстовых сообщений и аудиомодель для определения негативной эмоциональной окраски голосовых сообщений.

## Что делает проект

Affect Bot помогает администраторам поддерживать безопасную атмосферу в групповых чатах:

- анализирует текстовые сообщения на токсичность;
- обрабатывает голосовые и аудиосообщения;
- определяет агрессивный, оскорбительный или негативный контент;
- позволяет администратору выбрать уровень реакции бота;
- автоматически предупреждает, временно ограничивает или удаляет нарушителя.

Проект показывает практическое применение машинного обучения в пользовательском продукте: модель не лежит отдельно в ноутбуке, а встроена в рабочий Telegram-бот с понятной логикой модерации.

## Ключевые возможности

### Модерация текста

Для анализа сообщений используется готовая модель `cointegrated/rubert-tiny-toxicity`, основанная на ruBERT tiny. Она классифицирует русскоязычный текст и возвращает вероятность токсичности.

Бот реагирует на категории:

- `insult`;
- `dangerous`;
- `obscenity`.

### Модерация аудио

Голосовые сообщения скачиваются из Telegram, временно сохраняются и преобразуются в MFCC-признаки с помощью `librosa`. Далее признаки передаются в обученную Keras-модель `audio_sentiment_model.h5`, которая определяет вероятность негативного аудиосообщения.

### Настраиваемая строгость реакции

Администратор чата может управлять поведением бота командой:

```text
/setlevel 1
```

Доступные уровни:

| Уровень | Реакция |
| --- | --- |
| 1 | Предупреждение пользователя |
| 2 | Предупреждение и мут на 60 секунд |
| 3 | Удаление пользователя из чата |

```text
│   └── audio_sentiment_model.h5

```

## Как работает пайплайн

1. Пользователь отправляет текст, голосовое или аудиосообщение в Telegram-чат.
2. `python-telegram-bot` передаёт событие в соответствующий обработчик.
3. Текст отправляется в ruBERT-классификатор, аудио преобразуется в MFCC-признаки и анализируется Keras-моделью.
4. Бот сравнивает результат с правилами модерации.
5. В зависимости от уровня чата бот отправляет предупреждение, мутит пользователя или удаляет его из чата.

## Быстрый старт

### 1. Установить зависимости

```bash
pip install python-telegram-bot torch transformers tensorflow keras librosa numpy pandas scikit-learn openpyxl
```

### 2. Указать токен Telegram-бота

Создайте бота через [BotFather](https://t.me/BotFather) и укажите токен в `bot/main.py`:

```python
BOT_TOKEN = "your_telegram_bot_token"
```

### 3. Запустить бота

```bash
python bot/main.py
```

После запуска бот начнёт принимать сообщения через polling.

## Обучение аудиомодели

Файл `models/create_audio_model.py` содержит пайплайн обучения:

- чтение разметки из `dataset/prompt.xlsx`;
- загрузка аудиофайлов;
- извлечение MFCC-признаков;
- паддинг или обрезка признаков до фиксированной длины;
- обучение модели на связке CNN + RNN;
- сохранение модели в `audio_sentiment_model.h5`.
